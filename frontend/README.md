# CodeGuard frontend

React + TypeScript + Vite + Tailwind CSS + shadcn/ui.
See the README at the repository root for setup and run steps.

- `npm run dev` starts the dev server on http://127.0.0.1:5180 (calls to `/api` go to the backend on port 8100).
- `npm run build` type-checks and builds into `dist/`.
